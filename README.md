# Design4Sales · Telegram-календарь

Интерактивный рабочий календарь Telegram-канала Design4Sales на цикл `22.08.2026 – 03.10.2026`.

В календаре 19 основных публикаций, подробные визуальные сценарии, статусы подготовки, фактические метрики Telegram и контрольные срезы каждые две недели. Прогресс хранится локально в браузере.

## Как запустить локально

```bash
npm install
npm run dev
```

После запуска откройте локальный адрес, который покажет Vite.

## Как собрать проект

```bash
npm run build
```

Готовые статические файлы появятся в папке `dist/`.

## Как выложить на GitHub Pages

Вариант через GitHub Pages без CLI:

1. Загрузите папку проекта в GitHub-репозиторий.
2. Выполните `npm install` и `npm run build`.
3. В настройках репозитория откройте `Settings → Pages`.
4. Выберите публикацию из ветки или через GitHub Actions.
5. Если используете ветку `gh-pages`, можно установить зависимость и запустить:

```bash
npm run deploy
```

## Прогресс, статистика и анализ

Прогресс задач хранится в `localStorage` браузера. Для переноса на другой компьютер используйте:

- `Экспорт прогресса JSON` — скачивает файл с текущими статусами.
- `Импорт прогресса JSON` — загружает ранее сохранённый файл.
- `Сбросить прогресс` — очищает статусы, метрики и заметки в текущем браузере.

После публикации у каждой карточки можно записать просмотры, реакции, комментарии/ответы, пересылки и переходы. Раздел «Анализ каждые 2 недели» собирает контрольные показатели для периодов после 05.09, 19.09 и 03.10.

## Где лежат данные календаря

Основные данные находятся в:

```text
src/data/telegramPlan.js
```

Каждая публикация содержит формат, тип контента, одну основную мысль, визуальный сценарий, механику вовлечения, роль Лины, CTA и список материалов. Других площадок в модели данных нет.
