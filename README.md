# Design4Sales · Telegram-календарь

Календарь публикаций Design4Sales для Mac и веба. В «Плане» видны выбранные площадки, даты, время по Москве и напоминания. У темы есть одна отметка «Готово к выходу», а выход на каждой площадке отмечается отдельно. В «Плане» также показан ближайший график тем с изменяемыми датами-ориентирами. В «Темах» по нажатию заголовка открываются замысел, визуал и план подготовки, в «Архиве» — история.

«Настройки» содержат подключение Apple «Напоминаний», время по умолчанию и резервные копии. На iPhone задачи синхронизируются через iCloud. [Установка и проверка на устройствах](docs/APPLE-REMINDERS.md) · [Архитектура и сборка Mac](docs/REMINDER-ARCHITECTURE.md).

## Как запустить локально

```bash
npm install
npm run dev
```

После запуска откройте локальный адрес, который покажет Vite.

## Как собрать проект

```bash
npm run build
```

Готовые статические файлы появятся в папке `dist/`.

## Как выложить на GitHub Pages

Вариант через GitHub Pages без CLI:

1. Загрузите папку проекта в GitHub-репозиторий.
2. Выполните `npm install` и `npm run build`.
3. В настройках репозитория откройте `Settings → Pages`.
4. Выберите публикацию из ветки или через GitHub Actions.
5. Если используете ветку `gh-pages`, можно установить зависимость и запустить:

```bash
npm run deploy
```

## Прогресс, статистика и анализ

Прогресс задач хранится в `localStorage` браузера. Для переноса на другой компьютер используйте:

- `Экспорт прогресса JSON` — скачивает файл с текущими статусами.
- `Импорт прогресса JSON` — загружает ранее сохранённый файл.

Схема прогресса v5 использует тот же ключ браузера, что и v4, и читает предыдущие версии. Она сохраняет заметки, метрики и статус фактически опубликованного архива. Mac-приложение хранит план отдельно от браузера; для перехода перенеси его через JSON.

Старые заметки, статусы и метрики остаются в хранилище и экспорте JSON. В архивных карточках с такими данными доступен блок «Сохранённые данные».

## Где лежат данные календаря

Основные данные находятся в:

```text
src/data/telegramPlan.js
```

Не вышедшие темы первоначального плана вынесены из активной хронологии в:

```text
src/data/telegramBacklog.js
```

Каждая новая запись содержит аудиторию, одну мысль, источники для текста и визуала, основную площадку, лимит времени, порядок работы, блок «После публикации» и сроки проверки. Старый многоплатформенный план хранится только как архив тем.
